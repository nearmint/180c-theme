# Code promo

> Comprendre et utiliser nos codes de réduction.

---

## Qu'est-ce qu'un code promo ?

`slug: code-promo-definition`

Un code promo est une suite de caractères qui, appliquée au moment du paiement, déclenche une remise sur le total de votre commande. Nous les diffusons ponctuellement via notre newsletter, nos réseaux sociaux ou lors d'opérations spéciales.

---

## Comment utiliser mon code promo ?

`slug: code-promo-utilisation`

Une fois vos articles ajoutés au panier :

1. Cliquez sur l'icône du panier en haut à droite pour y accéder.
2. Repérez le champ « Code promo » sous le récapitulatif.
3. Saisissez votre code, puis cliquez sur « Appliquer ».
4. La remise s'affiche immédiatement dans le sous-total.
5. Finalisez votre commande : le montant réduit est reporté sur la page de paiement.

---

## Quelles sont les conditions d'utilisation ?

`slug: code-promo-conditions`

Chaque code promo a ses propres conditions : date d'expiration, produits éligibles, montant minimum de commande ou cumul avec d'autres offres. Ces conditions sont systématiquement précisées au moment de la diffusion du code.
